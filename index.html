Multi-Tier Architecture on AWS Cloud

Designed and implemented a multi-tier architecture on AWS consisting of a Web Server, Application Server and Data Server. The web server handles incoming user requests, while the application server processes application logic and communicates with the data server internally. The architecture uses Amazon VPC, subnets, route tables, security groups and a NAT Gateway to provide controlled network communication, security and internet access where required.

  • Created a VPC with public and private subnets.
  • Deployed the Web Server in the public subnet.
  • Deployed the Application Server in a private subnet.
  • Hosted the Data Server / database in the private layer.
  • Enabled internal communication between application and database tiers.
  • Used Security Groups to control traffic between tiers.
  • Used an Internet Gateway for required public connectivity.
  • Used a NAT Gateway for outbound internet access from private resources.
  • Used Terraform to provision and manage the AWS infrastructure.

Wireless Self-Powered I-V Curve Tracer

Designed and developed a portable wireless I-V curve tracer for real-time characterization of photovoltaic panels under varying environmental conditions. The system uses a non-intrusive disconnect circuit, battery-powered operation and Bluetooth connectivity to enable portable PV testing without interrupting the existing PV installation.
